# Laravel REST API Starter Kit

An API-only, production-ready **Laravel REST API Starter Kit** crafted with enterprise architecture standards, Action pattern, Sanctum authentication, Role-Based Access Control (RBAC), polymorphic attachments, unified image optimization, dynamic settings, audit trails, and automatic OpenAPI documentation.

---

## Key Highlights

- **PHP 8.4** & **Laravel 13** with strict typing (`declare(strict_types=1);`).
- **Clean Action Pattern (`app/Actions`)**: Decoupled, reusable single-responsibility business logic classes.
- **Consistent Response Standard**: Uniform JSON envelope (`status`, `message`, `data`, `meta`, `errors`) with centralized exception handling.
- **Declarative Query Builder (`app/Query`)**: Built on `spatie/laravel-query-builder` with filtering, sorting, searching, column selection, and eager includes (`?include=roles,permissions,attachments`).
- **API-only**: no frontend build, no Node.js, no session UI. Every account flow is a JSON endpoint.
- **Auth & RBAC**:
  - Laravel Sanctum bearer tokens that expire (30 days by default).
  - Two-factor authentication over the API (TOTP + recovery codes) with a login challenge step.
  - Password reset and signed email verification links, aimed at your own client app via `FRONTEND_URL`.
  - Optional "verified email required" mode, switched on at runtime from settings.
  - Spatie Laravel Permission with predefined roles (`Admin`, `User`), custom roles, and a rule that nobody can grant a permission they do not hold.
- **User Management**:
  - UUID Primary Keys & Soft Deletes.
  - Batch operations (Delete, Restore, Force Delete).
  - Excel Import & Export with downloadable template endpoint (`GET /api/v1/users/template`).
  - User Avatar upload with thumbnail auto-crop and old avatar cleanup.
- **Dynamic Application Settings**:
  - Database-driven settings with automatic type-casting (`string`, `boolean`, `integer`, `float`, `array`/`json`).
  - Current database reads so setting changes take effect across workers without stale cache values.
  - Public settings (`GET /api/v1/settings/public`) and Admin settings (`GET / PUT /api/v1/settings`).
  - System integration (e.g. `allow_registration` toggles public registration on/off).
- **Audit Trail & Activity Log**:
  - Spatie Activitylog tracking `created`, `updated`, `deleted` events with old vs new attribute changes and causers.
- **Polymorphic Attachable & Media Engine**:
  - **Many-to-Many Polymorphic** relation (`attachments` + `attachables`) via `HasAttachment` trait.
  - **Mobile-Friendly Two-Step Upload**: Upload file in background, then attach ID(s) to form payload.
  - **Multi-File Batch Uploads**: Supports both `file` and `files[]`.
  - **Reusable `ImageService`**: Auto-scales large phone photos ($\le$ 1920px), auto-rotates EXIF orientation, compresses quality (80%), and creates square thumbnails.
  - **Extensive Format Whitelist**: Documents (PDF, Word, Excel, PPT), Video/Audio, Archives (Zip, Rar), and **GIS / Geospatial** (`geojson`, `kml`, `kmz`, `gpx`, `topojson`, `gpkg`, `shp`, `mbtiles`, `tif`, etc.).
  - **S3-Compatible Ready**: Multi-disk tracking (`disk` column), supports **MinIO**, **Cloudflare R2**, **Wasabi**, **AWS S3**, and **Presigned Temporary URLs** for private files.
- **Interactive OpenAPI Documentation**:
  - Beautiful API reference generated by Dedoc Scramble at `/docs/api`.
  - Auto-exported OpenAPI specification at `api.json` (import directly into Postman, Bruno, or Insomnia).
- **Quality gates**: 200+ Pest tests, 100% type coverage, PHPStan level 7, Rector and Pint, all run by `composer test` and in CI.

## Installation & Quick Start

### 1. Clone & Install Dependencies
```bash
git clone https://github.com/liamsinami/laravel-rest-api-starter-kit.git
cd laravel-rest-api-starter-kit
composer install
```

### 2. Environment Configuration
```bash
cp .env.example .env
php artisan key:generate
```

Settings worth knowing in `.env`:

| Variable | Default | Purpose |
| :--- | :--- | :--- |
| `FRONTEND_URL` | empty | Your client app. Reset links go to `{FRONTEND_URL}/reset-password?token=…&email=…`; verification links go to `{FRONTEND_URL}/verify-email?url=<signed API URL>` (the app calls that URL). Empty: reset links use `APP_URL`, verification links hit the API directly. |
| `SANCTUM_EXPIRATION` | `43200` | Token lifetime in minutes (30 days). Expired tokens are pruned daily. |
| `API_DOCS_ENABLED` | `true` | `false` removes `/docs/api` entirely. |
| `MAIL_MAILER` | `log` | Set a real mailer before relying on reset and verification emails. |

Configure your database connection in `.env`:
```env
DB_CONNECTION=pgsql
DB_HOST=127.0.0.1
DB_PORT=5432
DB_DATABASE=laravel_rest_api_starter
DB_USERNAME=postgres
DB_PASSWORD=secret
```

### 3. Database Migration & Seeders
```bash
php artisan migrate --seed
```

This sets up tables, default roles (`Admin`, `User`), permissions, and default application settings. In local/testing environments only, it creates demonstration accounts:
- **Admin**: `admin@example.com` / `password`

Production administrators must be provisioned explicitly; production seeding never creates the demonstration administrator. An existing account is never promoted by the demonstration seeder.

After configuring a real mail transport, run `php artisan tinker` and create an administrator with your own email address:

```php
$admin = \Illuminate\Support\Facades\DB::transaction(function () {
    $user = \App\Models\User::create([
        'name' => 'Administrator',
        'email' => 'your-real-address@example.com',
        'password' => \Illuminate\Support\Str::password(32),
        'email_verified_at' => now(),
    ]);
    $user->assignRole('admin');
    return $user;
});
\Illuminate\Support\Facades\Password::sendResetLink(['email' => $admin->email]);
```

Set your password through the emailed reset link. Creating a duplicate email fails instead of promoting an existing account.

### 4. Create Public Storage Symlink
```bash
php artisan storage:link
```

### 5. Run the Server
```bash
php artisan serve
```

Access the interactive API documentation at:
**`http://127.0.0.1:8000/docs/api`**

In `APP_ENV=local` the docs are open. Everywhere else the browser asks for a basic-auth login: use an account with the `api_docs.view` permission (administrators have it). Basic auth skips two-factor, so grant this permission only to trusted accounts.

## Features & Usage Guide

### Security and upgrade notes

- Attachment API access is limited to the uploader or an administrator. User attachment changes are limited to that user or an administrator, and every linked file must also be accessible.
- The generic upload endpoint only accepts `User` as its attachable model. Other models can still use `HasAttachment`, but their endpoints must supply their own authorization.
- Private uploads use the private local disk when the selected disk is public. SVG uploads are not accepted.
- On an existing installation, run `php artisan attachments:secure-private` during maintenance to move private attachments off the public disk. Remove or quarantine previously uploaded public SVG files separately.
- Rotate any existing demonstration or shared import passwords. Password changes revoke existing personal API tokens.
- Accounts with confirmed two-factor get a `challenge_token` from `/auth/login` instead of a token. The challenge lasts 5 minutes, works once, and is dropped after 5 wrong codes.
- Only administrators may assign the administrator role or modify, delete or restore administrator accounts. Anyone else can only create, edit or assign roles whose permissions they already hold.
- Tokens expire after `SANCTUM_EXPIRATION` minutes. `?pat=` query tokens are accepted only on the attachment download route, because URLs end up in logs.
- Emails are stored lowercased; login, registration and imports treat `Bob@x.com` and `bob@x.com` as the same address.
- Turn on the `require_email_verification` setting to block unverified accounts. They can still call `/auth/me`, `/auth/logout` and `/auth/email/resend`.
- Batch endpoints accept at most 100 IDs. Permanently deleting a user also deletes their avatar and uploaded files.
- Spreadsheet imports accept at most 1,000 data rows and 50 columns from the first sheet, with a 50 MB unpacked workbook limit. New accounts require a password that meets the normal password policy; no shared password is assigned.

### 1. Attachable System (`HasAttachment` Trait)

Attach any files (documents, images, videos, audio, GIS geometries) to any Eloquent model:

```php
namespace App\Models;

use App\Concerns\HasAttachment;
use Illuminate\Database\Eloquent\Model;

class Project extends Model
{
    use HasAttachment;
}
```

**Common Helper Methods:**
```php
// Upload & attach single file
$project->attachFile($uploadedFile, description: 'Blueprint', isPrivate: false);

// Upload & attach multiple files
$project->attachFiles([$file1, $file2]);

// Link existing attachment ID(s)
$project->attachAttachment($attachmentId);
$project->attachAttachments([$id1, $id2]);

// Sync attachments (ideal for Android/Web form submissions)
$project->syncAttachments([$id1, $id2]);

// Detach relation without deleting the master file
$project->detachAttachment($attachmentId);
$project->detachAttachments(); // detach all

// Get attachments
$project->attachments;
$project->attachment(); // first attachment
```

### 2. Standalone `ImageService` (For Featured Images, Banners & Galleries)

For models that store image paths directly in their own columns (`featured_image`, `banner`, `gallery`) without creating attachment records:

Image output formats and generated extensions follow the detected file contents, not the uploaded filename; JPEG files named `.jfif` are stored as `.jpg`.

```php
use App\Services\ImageService;

class PostController extends Controller
{
    public function updateFeaturedImage(Post $post, UploadedFile $file, ImageService $imageService)
    {
        // Store the replacement before changing the saved path.
        $path = $imageService->store($file, directory: 'posts/featured', maxWidth: 1200);
        $oldPath = $post->featured_image;

        try {
            $post->update(['featured_image' => $path]);
        } catch (\Throwable $exception) {
            $imageService->delete($path);
            throw $exception;
        }

        $imageService->delete($oldPath);
    }
}
```

### 3. S3-Compatible Cloud Storage (Cloudflare R2, MinIO, Wasabi, AWS S3)

Switch from local storage to cloud object storage with zero PHP code changes:

In `.env`:
```env
FILESYSTEM_DISK=s3

# Cloudflare R2 / MinIO / AWS S3
AWS_ACCESS_KEY_ID=your_access_key
AWS_SECRET_ACCESS_KEY=your_secret_key
AWS_DEFAULT_REGION=auto
AWS_BUCKET=my-app-bucket
AWS_ENDPOINT=https://<account_id>.r2.cloudflarestorage.com # or http://127.0.0.1:9000
AWS_URL=https://cdn.my-domain.com # Optional custom domain / CDN
AWS_USE_PATH_STYLE_ENDPOINT=false # true for MinIO, false for R2/AWS
```

### 5. Firebase Cloud Messaging (FCM Push Notifications)

Full push notification support for Android, iOS, and Web clients via `laravel-notification-channels/fcm` (HTTP v1 API):

1. Place your Firebase service account JSON file at `storage/app/firebase-auth.json` (or set `FIREBASE_CREDENTIALS` in `.env`).
2. Register device tokens from your mobile app:
   ```http
   POST /api/v1/fcm/tokens
   Authorization: Bearer <token>
   Content-Type: application/json

   {
       "token": "fcm_device_token_from_mobile_sdk",
       "device_type": "android",
       "device_name": "Samsung Galaxy S24"
   }
   ```
3. Send notifications to users directly:
   ```php
   use App\Notifications\GenericFcmNotification;

   // Will automatically deliver to all active device tokens belonging to this user
   $user->notify(new GenericFcmNotification(
       title: 'Pesanan Baru!',
       body: 'Pesanan #1042 sedang diproses.',
       data: ['order_id' => '1042', 'screen' => 'order_details'],
       image: 'https://cdn.domain.com/banner.jpg', // optional
   ));
   ```
4. Revoke token on user logout:
   ```http
   DELETE /api/v1/fcm/tokens
   Authorization: Bearer <token>
   Content-Type: application/json

   {
       "token": "fcm_device_token_from_mobile_sdk"
   }
   ```
